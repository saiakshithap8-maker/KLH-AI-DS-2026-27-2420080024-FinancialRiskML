Abstract:

Financial institutions require accurate risk assessment to reduce loan defaults and identify high-risk customers. This project proposes an Explainable Machine Learning Framework for Predictive Financial Risk Assessment and Early Warning using the Give Me Some Credit Dataset. The data is processed through cleaning, EDA, feature engineering, feature selection, and class imbalance handling. Machine learning models such as Logistic Regression, Random Forest, XGBoost, LightGBM, and CatBoost are trained and compared using standard evaluation metrics. Optuna-based hyperparameter optimization is used to improve model performance and select the best optimized model. SHAP and LIME are applied to explain the factors influencing risk predictions. The predicted probability is converted into a risk score and classified as Low, Medium, or High Risk. An early-warning mechanism identifies high-risk cases, while an interactive Streamlit dashboard displays risk predictions, model performance, explanations, risk scores, and warning alerts.
